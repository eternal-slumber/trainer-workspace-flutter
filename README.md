# Trainer Workspace

Мобильное рабочее пространство фитнес-тренера на Flutter для Android и iOS.

## 1. Интерфейс

Стартовый `WelcomeScreen` содержит локальный логотип TW, название, описание и
кнопки входа и регистрации. Оформление следует Laravel Starter Kit: светлый фон,
чёрный основной текст и красные акценты. Общая тема находится в
`lib/core/theme/app_theme.dart`. Экран работает без сети и поддерживает прокрутку,
системные безопасные области и увеличенный шрифт.

## 2. Навигация

`AuthNavigation` использует стандартный `Navigator` и открывает существующие
`LoginScreen` и `RegisterScreen`. Проверка текущего маршрута предотвращает
повторные переходы из очереди нажатий. Оба экрана поддерживают возврат назад.

Стартовый экран выбирается в `lib/app/app.dart`. На текущем этапе приложение
открывает WelcomeScreen для неавторизованного пользователя. При подключении
авторизации проверку сессии и отдельное состояние загрузки следует добавить
перед выбором стартового экрана. Сохранённый токен или кэш не подтверждает сессию;
правила автономного доступа должны определяться отдельно от WelcomeScreen.

UI не обращается к API или SQLite. Будущие API Service, AuthRepository и
хранилище добавляются по мере реализации реальной функциональности, без пустых
сервисов и искусственного входа в рабочее пространство сейчас.

## 3. Проверки и запуск

```sh
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter run
```

Widget-тесты проверяют стартовый экран, локальные ресурсы, работу без HTTP,
переходы и возврат назад, повторные нажатия, маленькие экраны, масштабирование
текста, доступность и существующую форму регистрации.

Серверная авторизация, создание аккаунта, проверка сессии, SQLite и синхронизация
пока не подключены. Формы проверяют ввод локально и не создают пользовательскую
сессию.
